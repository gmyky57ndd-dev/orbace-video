# Shared marketing Remotion system

`Marketing.tsx` contains the reusable Orbace marketing primitives and the three review compositions:

- `MarketingEndCard` — deep green, crimson seal/wordmark, gold rules, URLs, and the Journal-derived signature.
- `OrbaceMarketingReplayV2` — 1080×1920 Replay proof cut.
- `OrbaceMarketingSolveRecordV1` — 1080×1920 record + replay cut.
- `OrbaceMarketingBrandFilmV1` — 1920×1080 product/brand story with voice, muted, and burned-caption variants.

Campaign-specific briefs, scripts, source notes, and review decisions stay under `marketing/<campaign>/`; this folder is the shared production system rather than three independent apps.
