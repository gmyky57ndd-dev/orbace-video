# Orbace Su-Pu Replay Trailer V6 --- Revision Notes

## Objective

Apply only the following refinements to regenerate V6. Keep everything
else from V5 unchanged.

-   **Strengthen the hook (0--2s):**
    -   Replace the opening caption with:
        -   **"This puzzle looked impossible."**
    -   Follow immediately with:
        -   **"Until this happened..."**
    -   Then cut to the contradiction frame.
-   **Build context before the contradiction:**
    -   Let viewers briefly see the branch forming before the
        contradiction appears.
    -   The contradiction should feel like the payoff, not the starting
        point.
-   **Make Replay the hero (not IB Tree):**
    -   After the silence beat, change the narration to:
        -   **"Let's replay it."**
    -   Immediately rewind using the real Su-Pu replay controls.
    -   Reinforce that replay---not the technique---is the product.
-   **Emphasize the chapter structure:**
    -   Hold each real chapter title approximately **0.5 seconds
        longer**.
    -   No additional narration or graphics.
    -   Allow viewers to recognize that Su-Pu organizes a solve into
        chapters.
-   **Revise the end card CTA:**
    -   Replace **"See how it ends"** with:
        -   **"Watch the complete replay"**
        -   **"Replay the thinking."**
    -   Drive viewers directly to the Su-Pu replay page.
-   **QR code variants:**
    -   Generate **two end-card versions**.
    -   **9:16 YouTube Shorts:** URL only. **Do not include a QR code**,
        since most viewers are already on a mobile device.
    -   **16:9 Desktop / Presentation:** Include a QR code in the lower
        corner with sufficient quiet zone.
    -   Prefer a **short branded redirect**
        (e.g. `orbacesudoku.com/r/ibtree`) that redirects to the full
        Su-Pu replay URL for cleaner presentation and campaign tracking.

## Guiding Principle

> The replay is the product.\
> Reveal the turning point, but never reveal the entire story.
