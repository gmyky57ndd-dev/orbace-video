# Replay V2 Remotion package

- Composition: `OrbaceMarketingReplayV2`
- Shared implementation: `tools/remotion/src/marketing/Marketing.tsx`
- Root: `tools/remotion/src/index.ts`
- Render command: `npx remotion render src/index.ts OrbaceMarketingReplayV2 <output>.mp4 --config=remotion.config.ts --codec=h264 --crf=22`

This campaign intentionally uses the shared project; it is not an independent Remotion app.
